# Claude Code に渡す指示文（コピペ用）

以下をそのままコピーして貼ってください。手順は上から順に。

---

## 手順0 ／ ファイルを置く

ZIPを解凍し、フォルダごとリポジトリに置いてコミットします。

```
salonrink/
└── design/
    └── miniapp-karte/     ← ここに解凍した中身を全部置く
        ├── README.md
        ├── screens/
        ├── png/
        ├── assets/
        └── ig/
```

---

## 手順1 ／ 最初に読ませる（1回だけ）

```
design/miniapp-karte/README.md を読んで、内容を要約して返してください。
実装はまだしないでください。

要約には次を含めてください。
- 画面が何枚あるか、それぞれの名前
- Design Tokens に定義されている色の数と、主要な5色
- タブバーの項目と順序
- 未確定として記載されている項目

このあと1画面ずつ実装を依頼します。
```

要約が正しく返ってこない場合は、READMEが読まれていません。手順1をやり直してください。

## 手順2 ／ 実装のルールを渡す（1回だけ）

```
実装のルールです。以降すべての作業で守ってください。

1. README.md の Design Tokens の値をそのまま使う。色・フォントサイズ・
   余白・角丸を独自の判断で変えないこと。
2. 文言は README と screens/ の .dc.html に書かれているものをそのまま使う。
   言い換え・改善・要約をしないこと。
3. screens/ の .dc.html は値の参照元。png/ は完成見本。
   実装は既存リポジトリの規約（Next.js App Router / 既存コンポーネント）に沿って
   書き直してよいが、見た目は見本と一致させること。
4. 1回の依頼で1画面だけ実装する。指定されていない画面・ファイルは触らないこと。
5. 既存の /neo 配下の redirect を変更しないこと。
   LINE Flexボタンの遷移先（/neo/diagnosis.html, /neo/ec.html）を壊さないこと。
6. app ディレクトリの位置をリポジトリで実確認してから書くこと。推測しないこと。
7. 美容・白髪に関する表示文言は薬機法サニタイズを通すこと。
   効能の断定表現を新たに追加しないこと。
8. 実装後、変更したファイルの一覧と、README の値と一致していることの
   確認結果を報告すること。

理解したら「了解」とだけ返してください。
```

- 値の参照元 … design/miniapp-karte/screens/画面02 ホーム（登録後）.dc.html
- 完成見本 … design/miniapp-karte/png/02-home.png
- 画像 … design/miniapp-karte/assets/

この画面以外のファイルは触らないでください。
実装が終わったら、変更ファイル一覧と、見本との差異があれば報告してください。

## 手順4 ／ ズレたときの指摘文

見本と違うものが出てきたら、指摘は具体的な値でしてください。

```
実装がREADMEの値と違っています。次を修正してください。

- カード背景 … 実装は #FFFFFF ですが、正しくは README の「面 #F7F3EA」です
- 見出しフォント … Shippori Mincho 500 / 22px です。ゴシックにしないでください
- 見出しの文言 … 「おかえりなさい、{名前}さんの髪のいま」です。変更しないでください

該当箇所だけを直し、他は触らないでください。
```

抽象的に「デザイン通りにして」と言うと直りません。**どの値が、どうあるべきか**を書いてください。

## 未確定のまま実装に入る項目

以下は決まっていません。実装時はプレースホルダのまま残すよう指示してください。

- 写真の無料保存枚数（README では 12枚 と仮置き）
- 写真の無料保存期間（README では 90日 と仮置き）
- 有料プランの価格（README では `¥---`）
- ホーム登録後の呼びかけ文言（「おかえりなさい、花子さんの髪のいま」は仮）

決まったら README を書き換えてから渡してください。

## 補足

- 1画面あたり1セッションが理想です。長いセッションでは前半の指示が薄れます。
- 「改善しないで」を明示しないと、Claude は善意で色や文言を整えます。
- `ig/` フォルダはSNS投稿用の素材です。実装には不要なので、渡すときに触らせないでください。
